## Short description

Find saved pages by what you remember. Recall brings private bookmark search to Edge and Chrome, with your favorites kept in their existing folders.

## One-paragraph introduction

Recall is a Novalon browser extension that helps you return to useful pages without hunting through your favorites. Click the toolbar button, enter a name, a topic or a short description, and open a matching saved link. Recall combines text matching with a bundled local meaning-search model, works across your current browser profile's bookmark folders, and can optionally remember a bookmarked page's title, description and headings. There is no account, API key or cloud search service to configure.

## Full product description

You saved it because it mattered: a useful tool, a promising idea, an article you wanted to revisit. Days later, you remember what it could help you do—but not what it was called or where you filed it.

Recall makes that return journey simpler.

Built for Microsoft Edge and Google Chrome, Recall adds a focused search window to your toolbar. Search a name when you know it. Search a folder when you remember where it belongs. Or try a short description of what the page does. Results show the saved title, website and folder so you can judge the match before opening it in a new tab.

Your existing favorites remain the starting point. There is no migration to a separate collection, no new filing system to learn and no need to reorganize everything before search becomes useful. Recall follows ordinary bookmark changes while letting you keep the folders that already work for you.

For a page with an unclear title, the optional Remember this page action adds context. While viewing a bookmarked website, open Recall and choose the action to save its title, description and headings on your device. Recall can use that snapshot to help retrieve the page later; it does not automatically visit your library or archive entire pages.

Privacy is part of the implementation. The model and runtime are included, searches run locally, and Recall makes no cloud AI or analytics calls. Its index saves progress while the popup is open and resumes at the next opening. Opening a result still connects to the destination website normally.

Recall is deliberately focused: click, search, open. It is for the pages you have already chosen to keep—and the moments when you need them again.

## Benefit-led feature copy

- **Find the idea you remember.** Search familiar words, topics or a short description; inspect related suggestions when the exact name escapes you.
- **Keep your folders.** Search across existing favorites without moving them to a new system.
- **Give vague pages better clues.** Optionally save a bookmarked page's title, description and headings locally.
- **Stay in your browser.** A toolbar popup, clickable results and keyboard controls keep the flow short.
- **Keep search local.** The included model runs on the device; no search account, cloud AI endpoint or remote favicon service is used.
- **Pick up where you left off.** Indexing progress is saved and resumes when Recall reopens.
- **Keep up with new releases.** Check for updates from About, then follow the in-place update steps and reload your existing installation. File replacement remains manual.
- **Bring remembered details with you.** Export context to a private local file, then import missing context for matching favorites into another Recall installation.

## Claims to keep accurate

- Say **local meaning-based suggestions**, not perfect recall or guaranteed semantic understanding.
- Say **existing browser bookmarks/favorites**, not every saved item across the internet.
- Say **tested in Edge and Chrome on Windows**, not universal Chromium/mobile support.
- Say **no cloud AI calls during search**, while noting that opening links makes normal website connections.
- Explain that **Check for updates** explicitly contacts GitHub for public metadata without including favorites, queries or page context. It is a manual check, not an automatic installer.
- Say **manual ZIP installation**, not “available in the Edge/Chrome store.”
- Do not claim automatic page summaries, full-page archiving, synchronization, live page monitoring, automatic updates or a new collection manager.
- The Edge Add-ons submission edition is prepared for automatic updates through Microsoft, but its listing is not live. Only change the public availability claim after approval and verification; the GitHub ZIP remains manual. Prepared store-specific copy is in `store/LISTING.md`.
- Do not describe Rust/WebAssembly alone as proof of low memory use. The bundled model/runtime dominate the download, and comprehensive battery/peak-memory measurements are not yet available.
